## 修复：刷新后台页被踢回首页 + 弹登录框

**实测结论**：SSR 读 `auth-token` cookie 是正常的（`next dev` 带 cookie 请求 `/dashboard`，RSC flight 里能看到 `initialToken`）。真正的问题是客户端把「SSR 没有 token」当成登出信号：

- `UserStateProvider` 里 `else if (userStore.token || user) { setToken(null); setUser(null) }`，只要 SSR 没读到 cookie（cookie 过期/被丢弃/iframe 下 SameSite=Lax 不发送），就把 localStorage 里的登录态整个清掉 → `AuthRouteGuard` 弹登录框 + `useDashboardGuard` 跳 `/`。
- 且 `useDashboardGuard` 原本 `if (!isAuthenticated || !user) replace("/")`，SSR 有 token 但 profile 补拉中也会被立刻踢走。

**改动**：
- `components/providers/UserStateProvider.tsx`：SSR 无 token 但本地有 token 时以客户端为准，并 `setToken(token)` 回写 cookie 自愈；只有本地也没有 token 才清空。补拉 profile 时打 `isProfileLoading`。
- `stores/useUserStore.ts`：新增 `isProfileLoading` / `setProfileLoading`（不进 partialize，不持久化）。
- `components/dashboard/useDashboardGuard.ts`：`isProfileLoading` 时先等待，`!user || !hasAdminRole` 才跳。

校验：`tsc --noEmit`、eslint 通过；dev 下带/不带 cookie 请求 `/dashboard` 均 200 正常渲染。
